# Changelog

## 2026.10.20

### 新增

- 航空电台新增 5 个频道：
  - 台北松山 RCSS（综合）
  - 檀香山 PHNL（塔台）
  - 新加坡樟宜 WSSS（综合）
  - 雅加达 WIII（离场 119.750）
  - 多伦多皮尔逊 CYYZ（进近 132.800）
- 为上述机场补齐坐标，选台后雷达与气象自动同步到该机场。

### 改进

- 低采样率流（≤11.025 kHz，多为 MPEG-2.5）改用 minimp3 解码；12 kHz 及以上使用 Helix。
- 音频任务在开机时预建 24 KB 连续栈，空闲 5 秒自动销毁并把内存还给 HTTPS；下次播放时按需重建。
- 离开「航空电台」页立即停止播放并归还解码器。
- 飞机照片链路：airport-data 直连失败后自动切换 weserv 代理重试；Planespotters 走转码代理。
- 重新生成中文字体子集，覆盖新增机场名和界面文案。

### 修复与校验

- 应用镜像与 bootloader 均通过 eFuse 无写入检查。
- 合并镜像通过 `tools/verify_firmware.py` 布局校验。
- 字体覆盖 373 个非 ASCII 码点。
- 新频道 mount 均可在二进制中定位。
- 真机验证雷达、气象、电台（含新增频道）和飞机照片正常。

## 2026.10.15

- 首次发布 Flight Mate Pro。
- 首页加入「航空电台」。
- 引入 minimp3 + Helix 双 MP3 解码器。
- 加入本场同步：播放电台时把雷达和气象切换到所选机场。
- 加入飞行日志、Wi-Fi 配网和深色航空仪表界面。
